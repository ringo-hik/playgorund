# AIChatOps 사용자 매뉴얼 (수정본)

## 1. 소개

AIChatOps는 다양한 전문 분야(페르소나)의 AI 어시스턴트와 대화하며 맞춤형 도움을 받을 수 있는 지능형 채팅 서비스입니다. 이 문서는 AIChatOps의 모든 기능을 효과적으로 사용하는 방법을 안내합니다.

## 2. 시작하기

### 2.1. 채팅창 열기

화면 우측 하단에 있는 동그란 채팅 아이콘을 클릭하여 AIChatOps를 시작하세요.

- **닫힌 상태**: 챗봇 아이콘
- **열린 상태**: 'X' 아이콘

### 2.2. 테마 및 언어 설정

채팅창 상단의 헤더에서 개인화된 환경을 설정할 수 있습니다.

- **테마 변경**: `AI`, `HT`, `HM` 버튼을 눌러 원하는 테마로 변경할 수 있습니다.
- **언어 변경**: `KR`/`EN` 버튼을 눌러 한국어와 영어 사이를 전환할 수 있습니다.

## 3. 핵심 기능

### 3.1. 페르소나 선택

AIChatOps의 모든 상호작용은 '페르소나'를 선택하는 것에서 시작됩니다.

1.  **카테고리 선택**:
    - **개인 특화**: 개인화된 AI 비서가 필요할 때 선택합니다.
    - **일반 문의**: 서비스 사용법 등 일반적인 질문이 있을 때 선택합니다.
    - **운영/관리**: 기술 지원이나 데이터 분석이 필요할 때 선택합니다.
2.  **페르소나 선택**: 선택한 카테고리에 속한 AI 전문가(페르소나) 목록이 나타납니다. 원하는 전문가를 선택하여 대화를 시작하세요.

### 3.2. 채팅

- **메시지 입력**: 하단 입력창에 질문을 입력하고 `Enter` 키를 누르거나 전송 버튼을 클릭하여 메시지를 보냅니다. `Shift+Enter`로 줄바꿈을 할 수 있습니다.
- **AI 응답**: AI의 답변은 왼쪽에 표시됩니다. 답변에 표나 코드가 포함된 경우, 가독성 높게 스타일링됩니다.
- **메시지 복사**: AI 답변에 마우스를 올리면 나타나는 복사 아이콘을 클릭하여 내용을 클립보드에 복사할 수 있습니다.

### 3.3. 고급 기능

입력창 하단의 버튼들을 통해 더 풍부한 대화를 경험할 수 있습니다.

- **질문 생성하기 (`✨` 아이콘)**: 현재 대화의 맥락에 맞는 새로운 질문들을 AI에게 추천받을 수 있습니다.
- **연속 대화 (`겹쳐진 아이콘`)**: 이 기능을 활성화하면, AI가 이전 대화 내용을 기억하여 더 자연스러운 문맥 유지가 가능합니다.

### 3.4. 피드백 보내기

서비스 개선을 위해 여러분의 소중한 의견을 보내주세요.

1.  메인 화면에서 **'피드백 보내기'** 버튼을 클릭합니다.
2.  **서비스 만족도**를 별점으로 평가합니다.
3.  **피드백 의견**을 텍스트로 작성합니다.
4.  **'피드백 보내기'** 버튼을 눌러 제출합니다.

## 4. 문제 해결

- **응답이 없을 경우**: 네트워크 연결을 확인하고, 잠시 후 다시 시도해 주세요.
- **오작동 시**: 채팅창을 닫았다가 다시 열면 대부분의 문제가 해결됩니다.

이 매뉴얼이 AIChatOps를 사용하는 데 도움이 되기를 바랍니다.
