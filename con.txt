ToDo 리스트를 작성할게 todo.md를 만들어줘 일단 1. SWDP BUILD에서 Project 선택 후 프로젝트를 변경할 수 있는 버튼이 필요해 그리고 프로젝트 하위 트리뷰로 Rel Build와 Layer Build, Commit Build가 있을거야  2. Layer Build와 Release Build Commit Build는 동일한 트리뷰를 갖을거야 (세팅은 개별) .swdp/{project_name}/rel-build.config layer-build.config commit-build.config 이런식으로 각각 세팅되도록 하면되고 프로젝트가 선택되면 SWDP로 부터 API를 요청하고 API로 부터 전달받은 REL, LAYER COMMIT 빌드 정보를 받아서 json에 덮어 써주고, 만약에 이미 파일이 있으면 기존 정보를 그대로 쓰는 구조로 할거야 3. Layer,rel,commit build의 하위트리는 Build Configuration이 열리고 고정적으로 Build, SAM, Coverity, DoBEE, OnBoard Test가 고정적으로 보이게 해주면되고 Enable 되어 있으면 체크박스 표기로 Enable 되어 있는 항목만 보여주면 되고 각 항목별로 완료, 대기, 진행중으로 표기해줘 (이건 SWDP에서 API로 전달) 그리고 Configuration Setting  항목이 있으면돼 이걸 클릭하면 아까 저장한 rel-build.config의 데이터를 수정 확인 가능한 설정 화면을 보여주면 좋아 on/off 설정도 있지만 build option 같은건 text로 입력해야해 각 별도 창을 띄워주면돼 모든 json의 항목들을 불러와서 수정가능한 창, 그리고 마지막으로 History 트리뷰가 있고 History의 하위 트리가 있으면 좋을거 같고 PUMBA REMOTE BUILD에 구현되어 있는 형태로 보여주면돼 REL LAYER COMMIT은 각각 빌드 Number가 있어서 Build #121 Success (완료 시간) 이런식으로 보여주면될거같아 (모든 빌드부터 onboard test까지) 모두 완료된 것만 History에서 보여주도록하고 이것도 SWDP로 API 호출을 통해서 가져온 데이터를 보여주는 형태로 구현해주면돼 보여주는 방식은 현재 Last Build보여주는 형태로  즉 프로젝트 - rel, Layer,commit Build  - Config 설정 히스토리 하위 트리뷰로 3개 있는거야 Start Build는 Layer Build, Rel Build, Commit Build 의 오른쪽에 재생 버튼을 누르면 확인 알람과 함께 시작되도록 하면돼 품바도 SWDP BUILD와 거의 동일하게 구성하고 품바는 프로젝트 설정이 없기 때문에 프로젝트 설정 및 REL LAYER 트리 옵션 없이 바로 Start Build, Configuration Setting, Build History 이렇게만 보여주면 될거같아 현재 빌드 진행중인건 Build In Progress 항목에서 보여주면 될거야 <- 이것들은 너가 구현하는게 아니라 todo.md에 요구사항을 빼먹지말고 모두 정리해
